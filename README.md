# React + Vite
# Web Lab 2: Drag and Drop Feature

## Технологии

- **React**: Используется для разработки пользовательского интерфейса.
- **React Context/State Management**: Для управления состоянием компонентов.
- **CSS**: Для стилизации интерфейса.
- **HTML5 Drag and Drop API**: Для реализации перетаскивания.

## Установка

1. Убедитесь, что на вашем компьютере установлен Node.js и npm.
2. Клонируйте репозиторий:
    ```bash
    git clone https://github.com/agartanah/web-lab2-continue.git
    ```
3. Перейдите в ветку `drag-and-drop`:
    ```bash
    git checkout drag-and-drop
    ```
4. Установите зависимости:
    ```bash
    npm install
    ```
5. Запустите проект:
    ```bash
    npm start
    ```
